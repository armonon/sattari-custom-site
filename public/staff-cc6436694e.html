Taken Contents

Download current saves a file to this computer. That is the only copy that survives losing the Netlify account — the nightly snapshots live in the same place as the data they protect, so they cover mistakes and bugs, not account loss. Keep a downloaded copy somewhere else.

Orders are not included: Stripe already holds every payment, and a second copy would only ever be the one that disagrees. Product photos are listed but not embedded. Restoring takes a snapshot of the current state first, so an accidental restore can itself be undone.
