# OpenClaw integration

Consolidates agent work into current main while preserving current catalog and
learning guides. The JSON inventory records every remote branch scanned,
explicit AGENT SATTARI commit attribution, and each open PR's disposition.
Other author names are not assumed to prove or disprove OpenClaw authorship.

Integrated: PRs 23, 25–38 (including original PR31 ancestry), with duplicate
repairs included once. Also includes the un-PR'd Split recovery checkpoint,
Node web-storage test isolation and retained master-gain diagnostics. The latter
runs as a separate manual workflow and cannot replace production qualification.

Includes Split, Key/BPM, Vox, Canvas, Pocket, Press, Lyric, Clean, Ableton exports,
PWA/offline support, suite/Locker handoff, portable analysis reports, safe Pocket
storage, capture/recovery and archive fixes, mixer tests and responsive layouts.
Public native alpha downloads are retired; their archives remain outside public/.

PR2 is superseded by current CI. PR3's NOW platform was deliberately removed
from main by e80a55e; restoring it would revive retired routes and backend access.
PR24 is the obsolete native download microsite, superseded by PR36 cleanup.
Their original source branches remain recoverable; no branches are deleted.
Closed PR21/22 are included through PR23. Other historical branches already
contained in main or patch-equivalent to the integrated work are not re-applied.

## Production boundary

Source consolidation is not evidence of production runtime parity. The live
Sattari site has additive files and 24 deployed functions with schedules, edge
configuration and traffic rules that must be preserved. The existing generic
whole-site CI deployment cannot prove this. Full production CI deployment now
requires SATTARI_FULL_DEPLOY_ALLOWED=true, which must only be set after exact
source/runtime parity is documented. Qualification jobs continue unchanged.
Do not turn the variable on merely to get a release out. Use a reviewed,
manifest-preserving overlay if parity remains unresolved.

No credentials, billing settings, live user data or existing hosted functions
are changed by this source integration. Real-device and music-corpus accuracy
qualification remain separate from automated fixture checks.
