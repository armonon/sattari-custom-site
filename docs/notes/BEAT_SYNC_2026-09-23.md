# Browser song-sync corrections

- Continuous project beat clock uses audio time; BPM changes preserve phase.
- Synced followers continuously compare fractional beat phase with their audible
  leader, including local tempo maps. Bounded +/-2% rate correction avoids
  repeated seek/restart. The project clock is the fallback when no leader plays.
- Only one controller owns follower rates; UI redraws and the older tempo-map
  timer no longer overwrite phase corrections.
- SYNC off removes the follower and restores independent speed. The sync timer
  is released when the final follower is disabled and on engine disposal.
- Beat / Bar (4) alignment is selectable per channel. Match All preserves the
  leader's position and joins it to project tempo at its current playing speed.
- GrainPlayer start offsets are corrected for Tone 15's rate-scaled conversion,
  so play, align and seek consistently use source seconds.

## Tests

`scripts/sync-audio-qa.html` renders the production GrainPlayer into Web Audio
OfflineAudioContext, not mocks. It never writes a user session or plays through
speakers. Two generated sources (120 / 100 BPM), project tempo changes, four-beat
seeks and key-lock off/on are tested. 30 measured transients per channel:

| Mode | Worst pair error | Gate |
| --- | ---: | ---: |
| No key lock | 0.021 ms | <20 ms |
| Key lock | 15.834 ms | <20 ms |

28 sync/transport/restore unit tests passed. TypeScript checking and the final
production build (including prerender) passed. The
full page suite passed earlier, but its latest rerun had 13/18 timeouts amid
extreme machine load and ~15 GB swap. A clean final UI regression rerun remains
required; no timeout thresholds were relaxed. No website deployment occurred.

These are synthetic audio alignment results, not certification of real-song
beat detection, stretch sound quality, browser background scheduling, hardware
latency or long-session reliability. The desktop Rubber Band result is tighter
(2.631 ms worst key-locked pair error); the two engines are not claimed identical.
